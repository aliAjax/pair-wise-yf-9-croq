# 桌游规则遗忘点卡片库

一个纯前端本地应用，用来管理桌游收藏中的规则遗忘点、常见争议、开局准备和计分提醒。支持按最近未玩、人数范围和复杂度筛选，并在详情里展示聚会前快速复习卡片。

直接打开 `index.html` 即可使用，也可以在本目录启动静态服务访问。

## 聚会试玩清单

在「聚会试玩清单」面板中按今晚的实际人数和时长排兵布阵：

- **主游戏**必须覆盖今晚人数（覆盖不了的游戏在下拉中不可选）。
- 最多再选 **两款副游戏**，副游戏不能与主游戏或彼此重复。
- 三款合计时长不得超过今晚时间窗口，面板上实时显示「合计 已用 / 窗口 分钟」。
- 任一条件不满足，本次修改会被**整次拒绝**并回滚，原清单和收藏保持不变，顶部会给出具体原因。
- **切换主游戏**时会先释放两款旧副游戏，再按新主游戏统一复核。
- 「缺失提醒」会同步提示：没有游戏支持当前人数、还没选主游戏、剩余时间放不下任何候选等。
- 所有下拉按「最近未玩」天数从久到近排序；被选入清单的游戏会在卡片和详情里标出主/副角色。
- 删除收藏中的游戏时，清单中对应位置自动清空。

全部数据（含聚会清单）只存在浏览器 `localStorage`（键名 `zfl18-boardgame-rule-cards`），刷新页面后自动恢复。
