# 桌游规则遗忘点卡片库

一个纯前端本地应用，用来管理桌游收藏中的规则遗忘点、常见争议、开局准备和计分提醒。支持按最近未玩、人数范围和复杂度筛选，并在详情里展示聚会前快速复习卡片。

## 聚会试玩清单

按今晚的实际人数和时长生成试玩安排：

- 选 1 款主游戏（必须覆盖实际人数）加最多 2 款副游戏；
- 三款合计时长不得超过今晚窗口，副游戏不能与主游戏或彼此重复；
- 任一条件不满足会**整次拒绝**（错误提示），原清单与收藏保持不变；
- 切换主游戏时先释放旧副游戏，再统一复核，失败则旧主游戏和旧副游戏全部保留；
- 候选与「最近未玩」排序、缺失提醒（无人可玩、时间放不下等）同步更新。

所有数据只保存在浏览器 localStorage 中，刷新页面后自动恢复；直接打开 `index.html` 即可使用，也可以在本目录启动静态服务访问。
